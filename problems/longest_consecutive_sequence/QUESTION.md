# Longest Consecutive Sequence

Given an unsorted integer array `nums`, return the length of its longest sequence of consecutive values.

The values forming the sequence do not need to appear next to one another in the original array. Design an algorithm with `O(n)` time complexity.

### Example 1:

> Input: `nums = [100,4,200,1,3,2]`<br>
> Output: `4`<br>
> Explanation: The longest consecutive sequence is `[1,2,3,4]`, which has length `4`.<br>

### Example 2:

> Input: `nums = [0,3,7,2,5,8,4,6,0,1]`<br>
> Output: `9`<br>
> Explanation: The values from `0` through `8` form a consecutive sequence of length `9`.<br>

### Example 3:

> Input: `nums = [1,0,1,2]`<br>
> Output: `3`<br>
> Explanation: The longest consecutive sequence is `[0,1,2]`.<br>

### Constraints:

> `0 <= nums.length <= 10^5`<br>
> `-10^9 <= nums[i] <= 10^9`<br>
