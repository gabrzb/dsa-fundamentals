# Two Sum

Given an integer array `nums` and an integer `target`, find the indices of two distinct elements whose values add up to `target`.

Exactly one valid pair exists for each input. The same array element cannot be used twice, and the indices may be returned in any order.

### Example 1:

> Input: `nums = [2,7,11,15], target = 9`<br>
> Output: `[0,1]`<br>
> Explanation: `nums[0] + nums[1] = 2 + 7 = 9`.<br>

### Example 2:

> Input: `nums = [3,2,4], target = 6`<br>
> Output: `[1,2]`<br>
> Explanation: `nums[1] + nums[2] = 2 + 4 = 6`.<br>

### Example 3:

> Input: `nums = [3,3], target = 6`<br>
> Output: `[0,1]`<br>
> Explanation: `nums[0] + nums[1] = 3 + 3 = 6`.<br>

### Constraints:

> `2 <= nums.length <= 10^4`<br>
> `-10^9 <= nums[i] <= 10^9`<br>
> `-10^9 <= target <= 10^9`<br>
> Exactly one valid answer exists.<br>
