# Valid Anagram

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and return `false` otherwise.

An anagram is a word or phrase formed by rearranging the letters of another word or phrase, using every original letter exactly once.

### Example 1:

> Input: `s = "anagram", t = "nagaram"`<br>
> Output: `true`<br>

### Example 2:

> Input: `s = "rat", t = "car"`<br>
> Output: `false`<br>

### Constraints:

> `1 <= s.length, t.length <= 5 * 10^4`<br>
> `s` and `t` consist of lowercase English letters.<br>

### Follow-up:

How would you adapt your solution if the input strings contained Unicode characters?
